# API fucking-great-advice.ru (v2)

Фактическая документация, собранная живыми запросами 2026-09-30. Публичной документации v2
нет — сайт использует эти ручки сам, а страница документации описывает только легаси v1.

## Конверт

Любой ответ v2 — JSON-объект:

```json
{ "status": "success", "errors": [], "data": [] }
```

- `status` — `"success"` или `"error"`;
- `errors` — массив строк (при ошибке, например `["No advices"]`);
- `data` — у `random-advices` и `tags` массив, у `latest` объект.

**Ошибки приходят с HTTP 200.** Проверять нужно поле `status`, а не код ответа:
`GET /api/v2/random-advices?limit=0` → `200 {"status":"error","errors":["No advices"]}`.

## Роуты

| Роут                                      | Методы                                 | Ответ `data`   | Статус                            |
| ----------------------------------------- | -------------------------------------- | -------------- | --------------------------------- |
| `/api/v2/random-advices`                  | `limit`, `startID`                     | массив советов | живой                             |
| `/api/v2/random-advices-by-tag`           | `tag` (обязателен), `limit`, `startID` | массив советов | живой                             |
| `/api/v2/latest`                          | —                                      | объект совета  | живой                             |
| `/api/v2/tags`                            | —                                      | массив тегов   | живой (самый медленный, флапает)  |
| `/api/random`, `/api/latest`              | —                                      | объект совета  | легаси: жив, но без `html`/`tags` |
| `/api/latest/5`                           | —                                      | —              | мёртвый: 404, тело — HTML         |
| `/api/random/censored`                    | —                                      | —              | мёртвый: 404, тело — HTML         |
| `/api/random_by_tag/<tag>`                | —                                      | —              | мёртвый: 404, тело — HTML         |
| `/api/v2/random-advices-by-tag` без `tag` | —                                      | —              | HTTP 400                          |

Неизвестные роуты (`/api`, `/api/v2`, `/api/v2/random` и т.п.) → 404 + HTML, поэтому
проверка `content-type` перед `response.json()` обязательна.

## Параметры выборки

| Параметр  | Значение   | Поведение                                                                                                                                                      |
| --------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `limit`   | целое ≥ 1  | Верхняя граница батча. Сервер отдаёт **не больше ~40** даже при `limit=1000`; часто на 1–4 меньше запрошенного (нестабильно). `limit=0` → ошибка `No advices`. |
| `startID` | id совета  | Указанный совет **встаёт первым**, остальные — случайные. Не хронология: при `startID=25000` в ответе встречались id > 25000.                                  |
| `tag`     | alias тега | Только у `random-advices-by-tag`. Пустой/неизвестный тег → ошибка `No advices`. Незнакомые параметры (`censored`, `tags`, `count`) сервер молча игнорирует.    |

Отдельной ручки «совет по id» нет: `startID=<id>&limit=1` + сверка `data[0].id`.
В батче нет повторов `id`.

## Совет

```json
{
  "id": 26385,
  "text": "Переверни блять календарь!",
  "html": "Переверни<br>блять<br>календарь!",
  "tags": ["life"],
  "conclusions": [{ "id": 26385, "text": "…", "html": "…" }]
}
```

- `text` — плоский текст, `html` — разметка сайта (`<br>`, `<span class="heighten">`);
- `tags` — массив alias'ов;
- `conclusions` — продолжение совета (та же страница, следующая «часть»); встречается редко;
- у легаси v1 вместо этого `{"id":…,"text":"…","sound":""}` — `sound` почти всегда пустая строка.

## Ограничения и особенности

- **Только HTTPS**: Android 9+ блокирует cleartext, `http://` даст `Network request failed`.
- **`Cache-Control: no-store, no-cache, must-revalidate`** — HTTP-кэша нет, каждый запрос идёт
  в origin; поллинг таймером бессмыслен.
- **Флапающий 500**: изредка (наблюдалось 2026-09-30) ручки отвечают 500 с HTML вида
  `yii\base\ErrorException: preg_match(): Allocation of JIT memory failed`. Транзиентная
  ошибка сервера — один повтор закрывает.
- **Цензуры нет**: ни в v1, ни в v2; `censored=1` игнорируется (у ~153 советов из 190
  при этом запросе в тексте мат). Маскировка — только на клиенте.
- **Латентность** (медиана 5 замеров, 2026-09-30): `random-advices` ~48 мс, `latest` ~38 мс,
  `tags` ~126 мс. Auth/cookies не нужны.
- Истории на сервере нет: «свайп назад» — только через локальный кэш, дедуп по `id` обязателен.
